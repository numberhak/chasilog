# 차시로그

교사용 수업 진도·학급 기록 프로그램 (Windows)

학급별 시간표와 수업 계획서를 넣어 두면 주간 진도표가 자동으로 만들어지고, 학급 점수·모둠·학생 기록을 한곳에서 관리합니다.

## 내려받기

오른쪽 **Releases**에서 가장 최신 버전을 고른 뒤, 아래 파일 중 하나를 받으세요.

| 파일 | 설명 |
|---|---|
| `Chasilog-Setup-x.x.x.exe` | 설치형 (권장). 관리자 권한 없이 설치되고 바탕화면·시작 메뉴에 바로가기가 생깁니다. |
| `Chasilog-Portable-x.x.x.exe` | 설치 없이 바로 실행 |

> 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. (코드 서명을 하지 않은 프로그램이라 나오는 안내입니다)

## 주요 기능

- **주간 진도표**: 시간표·수업 계획서·공휴일·학교 일정을 바탕으로 학급별 차시를 자동 배치. 결강·보강·내용 변경 시 진도가 알아서 밀림
- **컴시간알리미 반영**: 학교 코드와 교사 번호를 넣어 두면 그 주의 결강·보강을 가져와 진도표에 반영
- **수업 계획서**: 학기·기간별 계획서, 학급별 개별 수정
- **학급 기록장**: 학급 점수, 모둠 보드(모둠 수·인원 자유) 또는 개인 보드(최대 28명), 학급·모둠·개인 기록
- **엑셀**: 학생 명단 업로드(여러 학급 한 번에), 모둠·개인 기록 내보내기
- **백업**: 설정에서 백업 파일 내보내기·불러오기

## 개인정보 보호

- 로그인·클라우드가 없습니다. 모든 기록은 **내 컴퓨터**(`%APPDATA%\Chasilog`)에만 저장됩니다.
- 프로그램 화면은 인터넷에 접속하지 못하도록 막혀 있습니다.
- 인터넷을 쓰는 곳은 두 군데뿐이며, 학생 정보는 보내지 않습니다.
  - 컴시간 반영: 학교 코드와 주차만 컴시간 서버에 보냄
  - 업데이트 확인: 이 저장소의 최신 버전 번호를 읽기만 함

## 업데이트

새 버전이 나오면 프로그램을 켤 때 오른쪽 위에 알림이 뜹니다. 새 설치 파일을 받아 실행하면 되고, 기존 기록은 그대로 남습니다. 업데이트 전에 설정 › 데이터 보관 › **백업 파일로 내보내기**를 해 두면 더 안전합니다.
